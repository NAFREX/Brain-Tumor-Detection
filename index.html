Project Overview

What This Project Does

A binary image classification system that detects the presence of brain tumors in MRI scans using a custom CNN architecture trained on Google Colab with GPU acceleration.

Dataset

4,600 MRI brain scans sourced from a curated dataset with metadata including format, mode, and shape for each image.

Try the Model

Upload a brain MRI scan and the CNN model will predict whether a tumor is present — running entirely in your browser.

Setup Required — One Time Only
1
Open your Colab notebook and run the convert_model_colab.py script that was created in your project folder. It will download a file called tfjs_model_export.zip.
2
Extract the zip file. You'll get a folder named tfjs_model containing model.json and binary weight files.
3
Place the tfjs_model folder inside your project folder:
Brain Tumor Detection/tfjs_model/model.json
4
⚠️ Serve locally — The model won't load from file://. Use VS Code's Live Server extension (right-click index.html → Open with Live Server) or run:
python -m http.server 8000 then open http://localhost:8000
Click "Load AI Model" to initialize the neural network.
